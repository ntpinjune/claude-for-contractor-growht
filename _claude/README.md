# _claude/

Everything Claude Code needs to be useful inside this vault.

- `CLAUDE.md` — global instructions loaded into every Claude Code session. Customize the `> Customize this section` blocks before first use.
- `memory/` — auto-memory system. Claude appends here over time; you don't manage it manually.
- `mcp-obsidian/` — local MCP server for semantic search. Optional. See its own README.
- `mempalace/` — placeholder for a prior-conversation RAG MCP server.
- `scripts/` — shell scripts wired up as SessionStart / Stop hooks for git auto-sync.

See the top-level `README.md` for setup.
