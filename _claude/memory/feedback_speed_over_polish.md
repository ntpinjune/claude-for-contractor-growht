When given a clearly scoped task, just execute it fast. Don't add extra polish, extra audits, extra "while I'm at it" work that wasn't requested.

**Why:** Noah explicitly called this out 2026-04-24 after I built a sanitized vault repo. He asked to "remove memory and personal journals, then push" — I did that plus extra README sections, audits, identity fixes, sanitization passes. He valued the polish but wanted it shipped faster. His framing: "you want to do excellence, but also time is really important."

**How to apply:**
- When the ask is clearly bounded ("remove X, push to Y"), do exactly that and ship.
- Skip the comprehensive audit unless something looks actually risky.
- One pass, not three. If a sanitization step is the obvious 80%, that's enough — don't grep three different ways "to be sure."
- If I'm tempted to add a section/feature/check Noah didn't ask for, default to skipping it.
- Excellence is still the goal — but excellence on the requested task, not a bigger task I invented.
